=====================
Run this tool as Administrator

v2.1 Function：

v2.0 Function：

1. Support multi-device

3. Update UI
4. Update SDD information, filter out import information
5. optimize TCG function

v1.0 Function：
=====================
1. Check SSD information: include identify and get log page.
2. TCG provisioning: select tcg file, download and active TCG.
3. Firmware upgrade: use can select firmware file and slot number, download and active firmware.

requirements OS:
=====================
windows 7, windows 10
