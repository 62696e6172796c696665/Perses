Configuration Options

   

Sleep durations

The length of time in seconds to carry out the requested sleep action for each individual sleep states.
Default values are 30 for S1, S2 and S3 and 60 for S4.

State fallback (for sleep state that is not supported):

Allow the user to specify what to do if a requested sleep state is not supported.
 
Attempt lighter sleep:                Attempt the next supported lighter sleep (e.g. S2 instead of S3)
Attempt deeper sleep:                Attempt the next supported deeper sleep (e.g. S4 instead of S3)
Force sleep at requested level:        Try and force requested sleep state
Skip sleep:                        Skip requested sleep state.
 
The default value is “Skip Sleep”.

Cycle Forever

Select this to have Sleeper run the selected tests forever

Perform a Fixed number of Cycles

Select this and enter a number in the Number of Cycles field to have Sleeper run the selected tests a set number of times.

Number of Cycles

This is the number of times to run the selected test if the Perform a fixed number of cycles option is selected.

Cycle Interval Duration

The length of time in seconds to wait between sleep actions when carrying out ‘Cycle through all supported states’ or a ‘Cycle through all states’.

On Windows Vista the system may automatically return to its previous sleep state after several minutes if there is no user input, if this occurs the computer will not automatically wake again. To avoid this reduce the interval duration.

Restart automatically after power cycle

This option will automatically restart Sleeper if there was a problem during the last sleep and the computer had to be rebooted.

Stop and prompt user upon error

If this option is selected then if Sleeper is started and detects that it was in the middle of  a sleep last time it was running then a dialog box will be displayed with the option to continue testing, stop the test or exit Sleeper.

Sleep Forever

Put the system into the requested sleep state until it is woken up by user action such as moving the mouse.

Delay before first sleep

The length of time in seconds to countdown before entering the first requested sleep state.

Log to file

Select this option to save the logged messages from sleeper in a log file.

Clear log file at start

Select this option to clear the log file when Sleeper first starts testing.

Append to log file

Select this option to add new log entries to the existing log file without removing any existing entries.

Log file

This is the filename of the log file to store the results in.

Log level:

What level of detail you want in the log file.
 
Normal:                        Sleeper activity log
Debug:                        Sleeper activity log + trace log
Debug  & Events:        Sleeper activity log + trace log + System or Application event log + Wake Source.
 
The default value is “Normal”.

Note: Wake Source is available in Vista only and can describe the method the computer was awoken, eg "ACPILid" (open laptop) or "PowerButton". Timed events, like those set by Sleeper will usually return no wake source as such these will be replaced with "Unknown - Probably timer event".

Call external application between suspends

Select this option to run an application between suspends. The application location and name is entered in the File edit box below this option, the button will allow browsing the filesystem for the application.

Call external application after last cycle

Select this option to run an application after the last cycle has finished. The application location and name is entered in the File edit box below this option, the button will allow browsing the filesystem for the application.

Load Config

A dialog will appear to allow user to choose configuration file to load.

Save Config

A dialog will appear to allow user to save configuration settings as a configuration file.
